Fill this form to create a new blog post. No coding needed — it generates the code for you.

Save your GitHub token once — it's stored only in this browser and is never sent anywhere except directly to GitHub. After that, "Publish to GitHub" will push new posts to posts.js automatically, no manual copy-paste needed.

Add sections one by one. Use "Heading" for a sub-title and "Paragraph" for text.

Prefer to do it manually instead?
  1. Open the file posts.js in your website folder (or on GitHub).
  2. Find the line window.POSTS = [ near the top.
  3. Paste the copied code right after that line (so your new post shows first).
  4. Save and commit/re-upload the file.

⚠️ If you do it manually, also add this post's card to blog.html's grid and a new <url> line to sitemap.xml yourself — the "🚀 Publish to GitHub" button above now does all three automatically, manual copy-paste only updates posts.js.
